# 多用户，一人一份存档

和主机一样，游戏同一时刻以一个**用户**游玩，每个用户有自己的存档区。用户在设置面板（按 1，**用户**页）里管理（Mac）。

## 用户是什么

- 用户 = 一个 128 位 id + 一个名字。游戏的存档区就是以这个 id 命名的文件夹：
  `<profile>/save/<32 位十六进制>`（王国之泪的 profile 是
  `~/Library/Application Support/MacNativeGames/TOTK/profile`）。换用户就是换存档区。
- 名字会显示在游戏的存档界面里（游戏向账号系统询问，和主机一样）。
- 最多 **8 个用户**，和主机相同。第一个叫 "Local"。

## 选择用户

和主机一样，用户在**游戏启动之前**选定（系统为游戏打开的"预选用户"）。这里的选择放在设置面板里：

- **用户（下次启动生效）** 列出所有用户，选中一个后**下次启动游戏时生效**；正在运行的游戏保持它启动时的
  用户（它的存档区已经挂载，游戏中途切换会把两个玩家的进度混在一起）。
- **本次运行的用户** 显示当前游戏正在用的用户（灰显，运行中不可变）。
- **添加用户…**（页脚右侧）用游戏自带的文字输入条给新用户取名——输入条弹出时面板先收起，回车确认或
  Esc 取消后面板回来。最多 10 个字，和主机一样；名字会去掉首尾空白和控制字符。

游戏不会删除用户；存档文件夹会一直在，直到你自己删除（请先退出游戏）。

## 数据在哪里

- 用户存在 `<profile>/users.txt`，一行一个：行首可选的 `*` 标记下次启动生效的用户，随后是 32 位十六进制
  id、一个制表符和名字。整文件原子写入（写一半的文件不会存活），解析不了的行会被跳过，其余照常读回。
- 旧档案（只有单一身份文件 `account.uid`）的身份保留为用户 "Local"；`account.uid` 留着给旧版本用。全新
  档案不再写它。

## 说明

- 功能在运行时（runtime/account.c、runtime/users.h）；设置面板仅 Mac，iPhone / iPad 暂时没有切换用户的
  界面——存储本身在那里照常工作（一个用户 "Local"）。
- 每个用户的存档区是 `<profile>/save/` 下以用户 id 命名的文件夹，复制这个文件夹（备份、
  `games/totk/scripts/save_manager.py`）就带上所有用户；save_manager.py 导出导入的是当前用户（users.txt 标记的那个）。
- 测试：`tests/test_users.c`（存储：迁移、添加/切换、重启、损坏文件）与设置面板探针
  （`tests/test_settings_panel.py`，用户页，含通过文字输入条添加用户）。
